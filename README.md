# Glazok (Глазок) 👁️🛒

> **Ассистивный гибридный сканер ценников и товаров для незрячих и слабовидящих людей на Android.**

Glazok объединяет локальное машинное зрение реального времени (On-device ML Kit OCR & Object Detection) и облачную мультимодальную модель (Gemini VLM), обеспечивая мгновенную навигацию и детальное понимание товаров на полке магазина.

---

## 🌟 Основные возможности

1. **Реалтайм детекция объектов и распознавание текста (Контур 1 — Offline Fast-Path)**
   - Камера CameraX со связкой Google ML Kit (Object Detection & OCR) на 15–30 FPS.
   - Умный парсер ценников (`SmartPriceParser`): выделяет финальные цены, форматирует валюты (RUB, UZS, USD, EUR), отфильтровывает шум и штрихкоды.

2. **Глубокий анализ этикеток (Контур 2 — Cloud VLM Deep-Path)**
   - При тапе/запросе снимок отправляется в Gemini VLM для выделения состава, аллергенов, срока годности и предостережений.

3. **Аудио-тактильный интерфейс**
   - Арбитр голосовой очереди (`SpeechQueueArbiter`): приоритизация сообщений (экстренные предупреждения > цены > описание).
   - Тактильный виброотклик (`HapticManager`) для подтверждения наведения на ценник или объект.
   - Высококонтрастный HUD оверлей с подсветкой активных ценников.

## 🏗 Архитектура

Проект построен по принципам Clean Architecture и многомодульности:

```
Glazok/
├── app/                  # Android-приложение (CameraX, Compose UI, ML Kit, TTS, VLM)
├── core/
│   └── domain/          # Чистый Kotlin-модуль бизнес-логики и парсинга ценников
└── docs/
    └── architecture/    # Документация, диаграммы C4, ADR и журнал решений
```

Подробная архитектурная спецификация и диаграммы доступны в [docs/architecture/ARCHITECTURE.md](docs/architecture/ARCHITECTURE.md).

## 🚀 Сборка и запуск

### Требования
- Android Studio Ladybug / Koala или новее
- JDK 17+
- Android SDK 35 (минимальная версия Android 8.0, API 26)

### Сборка через Gradle
```bash
# Клонирование репозитория
git clone https://github.com/uzbekit54-gif/Glazok.git
cd Glazok

# Запуск тестов
./gradlew test

# Сборка debug APK
./gradlew assembleDebug
```
